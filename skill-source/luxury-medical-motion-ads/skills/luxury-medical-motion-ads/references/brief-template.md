# قالب خطة الإنتاج (إلزامي قبل التنفيذ)

انسخ القالب إلى `projects/<name>/brief.md` واملأه كاملاً، ثم اعرضه على المستخدم.

```markdown
# خطة إنتاج: <العنوان>

| البند | القرار |
|---|---|
| الفكرة | <جملة واحدة: ما الموضوع> |
| الرسالة | <جملة واحدة: ماذا يتذكر المشاهد> |
| الجمهور | <من، العمر، السياق> |
| نوع المحتوى | إعلان / تعريف خدمة / شرح تقنية / تثقيف / تغذية / أعضاء / توعية / رحلة تحسن / تعريفي طويل |
| المنصة والمقاس | <9:16 رئيسي + 16:9 + 1:1 …> |
| المدة | <ث> |
| الهوك | «<الجملة>» + <المشهد البصري في أول 2–3 ث> |
| الصوت | <نسائي/رجالي>، سعودي أبيض، <النبرة: دافئ/واثق/هادئ>، الإيقاع <−6%…>، الوقفات: <أين> |
| مسار الصوت | ElevenLabs (<voice id>) / مولّد الجلسة / Microsoft Zariyah/Hamed (مسودة) / تسجيل بشري |
| الموسيقى | <ambient-calm/hopeful/deep أو ملف مرخص> |
| الشعار | زاوية ثابتة (<الموضع>) + مشهد ختامي + <ظهور إضافي إن وجد> |
| الالتزام الطبي | <ما يُمنع قوله في هذا الموضوع + نص الإخلاء> |

## التعليق الصوتي (كامل)
<سطر = جملة = مشهد>

## تسلسل المشاهد
| # | المرحلة | الجملة | المشهد البصري | الحركة/الانتقال | المؤثر |
|---|---|---|---|---|---|
| 0 | Hook | … | … | … | riser |
| 1 | Problem | … | … | zoom | whoosh-soft |
| 2 | Explanation | … | 3D … + callouts | zoom | whoosh |
| … | Discovery | … | … | sweep | shimmer |
| … | Solution | … | … | blur | pop |
| … | CTA | … | الشعار الكبير + الدعوة + التواصل + الإخلاء | sweep | sweep |

## اللقطات والصور المطلوبة
- [ ] <وصف اللقطة> — المصدر: متوفرة / Stock (`stock.ps1 "<query>"`) / AI (<وصف ثابت للشخصية>) / 3D إجرائي / تصوير المركز
```

## أسئلة تحقق قبل الاعتماد
- هل يقول كل مشهد بصرياً ما تقوله جملته؟
- هل في الفيديو 3 أنواع مشاهد مختلفة على الأقل؟
- هل يربط انتقال واحد على الأقل بين مشهدين بشكل متشابه (match cut)؟
- هل كل رقم أو معلومة طبية مصدرها المستخدم أو مرجع موثق؟
- هل الهوك مفهوم بدون صوت (بالنص على الشاشة)؟
